*   **Ручное тестирование:** Функциональное, регрессионное, исследовательское тестирование веб- и мобильных приложений (Android).

## Инструментарий тестирования (детали)

*   **Postman:** автоматизация запросов, написание тестов на JavaScript для проверки статусов и схемы ответа.
*   **Charles:** сниффинг HTTPS-трафика, маппинг (подмена) ответов бэкенда для эмуляции edge-кейсов.
*   **Docker:** поднятие тестовых баз данных и бэкенд-сервисов локально без танцев с бубном.
*   **Android Studio:** логгирование через Logcat, тестирование на разных версиях API через эмуляторы.
